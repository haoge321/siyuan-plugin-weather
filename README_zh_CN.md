# 状态栏天气

![状态栏天气预览](status-preview.png)

状态栏天气是一款简单实用的思源笔记天气小组件。它会在思源底部状态栏显示手绘风天气图标、实时天气和气温，还支持一键把当前天气插入文档，写日记必备。

> 还没有高德 API Key？[查看获取教程](https://www.showdoc.com.cn/siyuanPluginWeather/11559060627523622)

悬停在状态栏天气上，即可查看温度、湿度、风向和风力。

## 功能特点

- 状态栏显示手绘风天气图标 + 实时天气 + 气温（图标可在设置中关闭）
- 斜杠命令 `/天气`：在文档中插入“图标 + 天气 + 气温”
- 斜杠命令 `/天气（详细）`：额外插入湿度、风向、风力
- 插入文档的图标自动保存到 assets 目录，随笔记同步，换设备不丢失
- 支持查看温度、湿度、风向和风力
- 支持搜索城市和区县名称
- 支持区县级及以上地区选择
- 支持每 5、10、30、60 分钟自动刷新
- 点击状态栏天气即可手动刷新并查看详细信息

## 插入天气到文档

在编辑器中输入 `/天气` 即可把当前天气插入文档，选择“天气（详细）”还会带上湿度、风向和风力：

![插入天气到文档效果](doc-insert-preview.png)

## 使用方法

1. 前往高德地图开放平台申请 Web 服务 API Key。
2. 打开思源插件设置，进入“状态栏天气”设置面板。
3. 填写高德 API Key。
4. 在“天气城市”中搜索并选择城市或区县。
5. 选择自动更新时间并保存。

配置成功后，天气会显示在思源底部状态栏。点击天气文字可以立即刷新，并查看温度、湿度、风向和风力等信息。

## 注意事项

- 天气城市至少选择区县级地区，不支持乡镇、街道等更细的区域。
- 本插件使用高德地图天气接口，仅提供实时天气，不包含天气预报。
- API Key 和天气城市会保存在思源的插件数据中。
- 查询天气时，插件会将请求发送到高德地图天气服务。
- 如果天气显示获取失败，请检查 API Key、网络连接和高德服务权限。
